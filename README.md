## Контекстно-зависимые условия:
### Уникальность идентификаторов
Пример: #define S(x, x) (x + 1);  
Ожидаемое сообщение: "Одинаковые параметры в аргументах"  

### Использование идентификаторов
Пример: #define S() (x + 1);  
Ожидаемое сообщение: "Неизвестный аргумент: x"  

## Структура AST:
### Описание типов узлов
1. \<function-call> - объявление макроса;
2. \<identifier> - объявление идентификатора (имени функции, имени операнда);
3. \<function-param> - объявление параметров функции;
4. \<list-param> - параметры функции;
5. \<macros body> - объявление тела макроса;
6. \<expression> - объявление выражения;
7. \<exspression-body> - объявление множества операндов;
9. \<term> - объявление операнда;
10. \<operator> - объявление оператора.
